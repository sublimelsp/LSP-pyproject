Breaking changes:

- The key used to override LSP-pyproject settings in project settings has changed from `pyproject` to `LSP-pyproject`.
  If you use project-specific overrides for LSP-pyproject, you have to rename the key for them to apply:

  Before:

  ```jsonc
  {
      "settings": {
          "LSP": {
              "pyproject": {
                  // ...
              }
          }
      }
  }
  ```

  After:

  ```jsonc
  {
      "settings": {
          "LSP": {
              "LSP-pyproject": {
                  // ...
              }
          }
      }
  }
  ```
